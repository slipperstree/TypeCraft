# TypeCraft

TypeCraft 是一个为 [Typecho](https://typecho.org/) 制作的 Minecraft 灵感像素风博客主题。以草地方块、立体按钮和复古游戏界面为视觉语言，兼顾中文阅读与移动端布局。

> 非 Mojang / Microsoft 官方产品；与 Minecraft 官方无关联。主题视觉由 CSS 实现。

## 功能

- 草地、泥土和天空配色的响应式布局，文章卡片及侧边栏
- 首页与列表页上下分页、分类文章数量、文章搜索、归档与独立页面
- 原生评论及嵌套回复、评论时间格式与头像布局
- 首页弹窗登录，密码可见性切换及错误提示
- 登录后按 Typecho 权限显示管理菜单、文章编辑入口
- 无需依赖 Handsome 插件的搜索功能

## 安装

1. 下载本仓库，解压后将主题文件夹命名为 `TypeCraft`。
2. 上传至 Typecho 网站的 `usr/themes/TypeCraft/`。
3. 在 Typecho 后台 **控制台 → 外观** 中启用 TypeCraft。
4. 建议启用 HTTPS，并检查固定链接、评论和搜索功能。

**要求：** Typecho 1.2.x；PHP 版本以所使用的 Typecho 版本支持范围为准。开发环境为 Typecho 1.2.1 / PHP 8.5，其他版本尚未系统测试。

## 使用说明

- 顶部导航自动读取独立页面。
- 搜索使用 Typecho 自带的 `?s=关键词` 路由。
- 登录使用 Typecho 原生验证机制，不会在主题中存储密码。
- 编辑入口仅对有权限的登录用户显示。
- 评论设置、账号权限、文章分类在 Typecho 后台管理。

## 已知限制

- 弹窗登录的错误反馈依赖前端对登录响应页面的判断，尚未覆盖所有第三方认证插件及复杂跳转场景。
- 主题中包含适配旧 Handsome 编辑器的兼容资源路径，但第三方 Handsome 资源不随开源仓库分发；若需使用其编辑器，请自行确认兼容性及授权。
- 目前没有自动化视觉回归测试。

## 开发

修改 `style.css` 及相应 PHP 模板即可定制。建议先在测试环境验证，再部署到生产站点。欢迎通过 Issue 反馈问题或提交 Pull Request。
